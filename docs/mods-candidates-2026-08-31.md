# 모드 · 스킨 추가 후보 (2026-08-31 조사)

현재 `data/mods.json` 은 디스코드 `#game-modifications` 채널만 옮긴 것이라 항목이 39개다.
PSOBB 모드 씬의 실제 중심은 **Pioneer2(Ephinea) 포럼**과 **Ephinea Wiki 스킨 저장소**이고,
채널에서 "이건 어디서 구해요" 소리가 나올 때 링크로 던져지는 물건들이 대부분 거기 있다.

아래는 그 바깥에서 찾은 후보다. **표에 ✅ 가 붙은 것은 2026-08-31 에 이미 `mods.json` 에 들어갔다.**
나머지는 아직이다 — 하나씩 확인하고 넣으면 된다.
`cat` 값은 기존 분류 키(character / effect / sound / ui / object / background / tool)에 맞춰 적어 뒀다.

## 확인 필요 / 주의

- 기존 `sources` 의 **Univers-PS Skin List** (`universps.online.fr`) 는 이번 조사에서 **접속이 거부됐다.**
  죽었을 가능성이 있으니 직접 확인하고, 죽었으면 표시하거나 빼는 게 좋다.
- Ephinea Wiki 항목은 위키 페이지에 다운로드가 붙어 있다. 파일이 아니라 **위키 페이지로 링크**를 걸면
  나중에 파일이 갱신돼도 안 깨진다.
- Nexus / GameBanana 는 다운로드에 로그인이 필요할 수 있다.
- 미리보기 이미지는 아직 하나도 없다. 원작자 스크린샷을 쓰려면 허락을 받는 편이 안전하고,
  아니면 기존처럼 자리표시자로 둔다.
- 위 목록은 **링크 존재만 확인**했고, 실제 파일이 살아 있는지 · Destiny 클라이언트에서 도는지는
  확인하지 않았다.
