How this works

  • The password is the only key — there is no account and no recovery. If you forget it, staff can remove the entry for you but nobody can tell you what it was. It is stored as a one-way hash, never as text.
  • Make one up for this page — it guards a line on a public list, nothing more. Never reuse a password you use anywhere that matters.
  • One entry per person, all your characters in it — most people here run several, which is the whole reason this page exists. Put them all in the one field and the search will find you by any of them.
  • Anyone can type any Discord name — the password stops others editing your entry, but it cannot prove the Discord name is yours. Treat the list as helpful, not as proof. Staff can remove entries that impersonate someone.
