PSOBB-Tools

I made this tool to smooth out as many of PSOBB's pain points as possible and make the game more enjoyable to play.

Rooms you create with the room shortcuts are now counted for you. The overlay parks itself in the top-right corner of the game window and keeps a separate tally for EP1, EP2 and EP4, so you can farm a run without keeping score in your head.

How to use it

  • Run PSOBB-Tools.exe from your PSO folder and allow the admin prompt. The hotkey only fires while the PHANTASY STAR ONLINE Blue Burst window is active.
  • Press Win + Numpad0 in-game to show or hide the counter. The tray icon carries the same toggle under Show/Hide Room Counter.
  • Create rooms the usual way with Win + Numpad4 (EP1), Win + Numpad5 (EP2) or Win + Numpad6 (EP4). Each room adds +1 to that episode on its own - there is nothing extra to press.
  • Every count also flashes as a small EP badge in the top-right of the game window for two seconds, so you can confirm a room registered without opening the window at all.

Reading the window

  • CURRENT is your run counter. It moves only when you create a room or press Reset Current, so you can keep one farming session in it.
  • TODAY is a daily tally. It clears itself the moment the date changes, so you never reset it by hand.
  • TOTAL adds EP1, EP2 and EP4 together for each column.
  • OVERLAY OPACITY sets the window between 30% and 100%. The value saves the instant you move the slider, and the flash badge uses it too.
  • PINNED: ON keeps the overlay on screen and brings it back a few seconds after the script starts. Press it to switch to OFF and the overlay hides itself five seconds later.
  • Undo Last takes back the newest +1 - handy when a room creation misfires. It remembers a single step, so use it right away.
  • Reset Current / Reset Today each zero out only their own column.
  • Counts are written to your user folder, so closing the tool or rebooting does not lose them: %UserProfile%\PSOBB-AHK\config.ini
