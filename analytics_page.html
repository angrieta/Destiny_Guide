      How these counts work

      Each page, feature view and action is counted at most once per browser tab session. Views are not unique people. Foreground means 15 seconds with the tab visible; section views mean at least 2 seconds intersecting the viewport, not proof of reading. Interactions include links, filters, searches and controls; input values are never sent. Feature counts are not additive. Dates are UTC.

      The analytics database stores only daily totals by page and fixed action label, without IP addresses, cookies or device identifiers. Network providers may process normal request metadata. Public counters are approximate and can be inflated; they are not an audited audience measurement.
