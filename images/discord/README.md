- 본문 이미지에는 무엇을 증명하는 장면인지 캡션을 붙인다.
- 같은 원본이 여러 채널에 재첨부됐을 때는 페이지에는 한 번만 노출한다.

- Discord 사용자 이름이나 개인 대화가 보이는 캡처는 사용하지 않는다.
