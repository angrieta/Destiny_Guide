Before you install anything

  • Back up the file you are replacing — a skin is a straight file swap, so keeping the original is the only way back. Most of these are a single archive you unpack into the game folder.
  • Skin packs go in the scene folder — this is the one placement the staff has stated outright. Other mods vary by file: a loose plRtex.afs is a character texture, while a .zip or .rar usually carries its own folder layout.
  • If the game crashes after a mod — put the original file back first, then report it. The staff have asked people to confirm a mod is not the cause before filing a bug.
  • Remapping keys is allowed, automating play is not — tools such as AutoHotkey may be used to remap keys. Automating gameplay in any way is not permitted.

Where these came from

These files are hosted on the authors' own accounts, so links do break. If one is dead, the forum thread is the place to look before asking in Discord.
