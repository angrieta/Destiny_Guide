# 번역 사전

- `en` 은 파일이 없습니다. 영어는 HTML 안의 원문을 그대로 쓰기 때문입니다.
  그래서 사전에 키가 빠져도 영어로 안전하게 표시됩니다.
- 키 이름은 `페이지.영역.항목` 형태입니다.
- **게임 데이터는 번역하지 않습니다.** 아이템명(DARK FLOW), 스탯 표기(ATP : 320 - 350),
  스페셜(Charge), 클래스명(HUmar), Section ID(Viridia) 는 전 세계 PSOBB 플레이어가
  영어로 씁니다. 번역하면 검색과 소통이 오히려 어려워집니다.
- **길이 주의.** 헤더 내비처럼 폭이 빡빡한 곳은 영어보다 길어지면 레이아웃이 밀립니다.
  프랑스어/스페인어는 영어보다 20~30% 길어지는 경향이 있어 축약형을 씁니다.
  수정 후에는 반드시 `node _qa/snap_i18n.mjs` 로 5개 언어 레이아웃을 확인하세요.
