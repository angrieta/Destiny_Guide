How to read this

  • ID only — at this difficulty nobody else can get it. If you want one of these, this is the ID to be on, and if you already are, this is your list.
  • The rate is the best one available — when several enemies drop the same item, only the best is shown, so the enemy column is where you should actually go.
  • The number badge — the rating this item has on the operator priority list, out of 10. When an item is rated higher only with a specific unit, the higher figure is shown; the item page has the condition.
  • Hit — how much this weapon wants Hit%, S down to C. A C-grade weapon is fine to keep without Hit.
  • The arrow — this item is a material. What it turns into is listed after the arrow, so it is worth picking up even when it looks plain.
  • DAR — the chance that enemy drops anything at all. A high rare rate on a low-DAR enemy is worse than it looks.
  • Remember that drop rates are divided by the number of players in the room, so a full party sees each rate roughly halved compared with going alone.
